# Одиссея: близко к тексту

Независимое современное русское прозаическое переложение «Одиссеи» с построчной сверкой и историко-культурными комментариями. Это не воспроизведение какого-либо современного перевода и не академическое критическое издание.

Текущий статус: `0.2.1-preview.1`. Песни I–II доступны как развёрнутые пилоты;
Песни III–XXIV — только сжатые черновые конспекты, которые нельзя считать полным
переложением. Числовая карта охватывает `12 110` строк, но не доказывает
смысловую полноту. Человеческая содержательная проверка не заявлена.

Планируемый сайт: <https://dzirtik.github.io/odyssey-modern-ru/>

## Локальный запуск

```sh
npm ci
npm run dev
```

Полная проверка:

```sh
npm run check
```

## Структура проверки

- `src/data/sources.yml` — карточки источников;
- `src/data/rights.yml` — реестр прав;
- `src/data/knowledge-state.yml` — моменты раскрытия фактов;
- `src/data/line-map/book-XX.yml` — непрерывное покрытие строк всех песен;
- `editorial/` — карты, независимые отчёты и решения;
- `EDITORIAL_AUDIT.md` — аудит глубины, обнаруженные разрывы и пороги статусов;
- `scripts/` — блокирующие автоматические проверки.

## Редакционные статусы

- `draft` — конспект или незавершённый текст; публикация допустима только с
  явным предупреждением;
- `editorial_preview` — развёрнутый материал, прошедший автоматизированные
  ролевые проверки, но не человеческую экспертизу;
- `editorially_approved` — статус зарезервирован для зафиксированной
  содержательной человеческой проверки после закрытия блокеров.
