# Методология

Работа идёт по песням и диапазонам строк. Для каждого диапазона фиксируются события, говорящий, адресат, формулы, неоднозначности и впервые доступные факты. Независимый русский черновик не строится на современном переводе.

После черновика создаются:

1. карта непрерывного покрытия строк;
2. локальные заметки с источниками, слоем и уверенностью;
3. независимые ролевые отчёты;
4. сводка решений;
5. проверки источников, прав, покрытия, спойлеров, ссылок и сходства.

Автоматическое покрытие означает только наличие связи с каждой строкой, а не гарантированную полноту смысла. Статус `editorially_approved` требует реальной содержательной проверки; текущий пилот имеет статус `editorial_preview`.
