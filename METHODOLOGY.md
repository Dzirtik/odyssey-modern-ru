# Методология

Работа идёт строго по одной песне. Для каждого диапазона фиксируются события,
говорящий, адресат, причинно-следственные связи, формулы, неоднозначности,
впервые доступные факты и вопросы читателя без классического образования.
Независимый русский черновик не строится на современном переводе.

После черновика создаются:

1. карта непрерывного покрытия строк;
2. локальные заметки с источниками, слоем и уверенностью;
3. независимые ролевые отчёты;
4. сводка решений;
5. отчёты филолога-гомериста, историка/археолога, религиоведа, литературного
   редактора, критической «красной команды», нового читателя, спойлер-аудитора,
   фактчекера/библиографа и специалиста по правам;
6. редакторская таблица решений: замечание, действие, состояние и открытый
   блокер;
7. проверки источников, прав, покрытия, глубины, спойлеров, ссылок и сходства.

Автоматическое покрытие означает только наличие связи с каждой строкой, а не
гарантированную полноту смысла. Порог глубины обнаруживает грубо сжатые тексты,
но не заменяет филологическую сверку.

Текущая публикация содержит один `editorial_preview` (Песнь I) и двадцать три
`draft` (Песни II–XXIV). Статус `editorially_approved` требует реальной,
зафиксированной человеческой содержательной проверки; сейчас его нет ни у одной
песни.
