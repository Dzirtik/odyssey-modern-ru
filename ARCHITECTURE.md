# Архитектура

## Выбор

Astro 7.1.3 выбран как зрелый генератор статических сайтов: он создаёт готовый HTML, позволяет свести клиентский JavaScript к небольшим локальным улучшениям и имеет официальный сценарий размещения на GitHub Pages. Сайт не использует серверную базу, аккаунты, аналитику, cookies, удалённые шрифты или сторонние клиентские скрипты.

## Размещение

В GitHub Actions `site` равен `https://dzirtik.github.io`, а `base` вычисляется из имени репозитория. Локально `base` равен `/`. Артефакт `dist/` загружается официальным `actions/upload-pages-artifact` и публикуется `actions/deploy-pages`.

## Доступность и устойчивость

Используются семантические landmarks, ссылка пропуска навигации, видимый focus, клавиатурно доступные `details`, системные шрифты, светлая/тёмная тема, `prefers-reduced-motion` и печатные стили. Настройки чтения и позиция хранятся локально.

## Данные

Текст пилота хранится как типизированные диапазоны; источники, права, знания, заметки и карта строк — в YAML. Валидация выполняется до сборки и публикации.
